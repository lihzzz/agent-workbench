# Agent Workbench

Agent Workbench is a desktop workspace for running AI coding agents in one place.

It is maintained at:

https://github.com/lihzzz/agent-workbench

## Features

- Claude Code, Codex, OpenCode, and ACP agent sessions
- Persistent project workspaces and chat history
- Built-in terminal, browser, Git panel, file preview, and MCP management
- Tool call rendering with diffs, logs, task progress, and attachments
- Prompt templates, subagents, usage views, and multi-agent relay workflows

## Development

```bash
pnpm install
pnpm dev
```

Useful commands:

```bash
pnpm build
pnpm test
pnpm dist
```

## Notes

This is a maintained desktop client derived from the Harnss codebase, with local changes and project direction managed in this repository.
